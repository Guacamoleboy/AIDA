# Internal or External ... ?

This file is provided to clarify any issues regarding this manner.

## Internal

### Used for

Internal is used for response and requests provided internally. Meaning within the system itself. Let's say data
travels from specific software to other parts of software. This is our internal structure.

This could be:

- DTOs needed internally.

## External

### Used for

External data being sent into the system or out of the system.

This could be:

- Final assessments provided to the frontend for final response.
- Each criterion specified individually.
- Assessment submission provided by the frontend sent to the backend.
