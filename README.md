**What are my expectations prior to starting the course?**

**How do I think AI will change the industry? If at all?**

> AI is probably here to stay. I don't see it as a threat at all. I see it as a feature that needs to be limited and used correct. I see a lot of people using AI blatantly without a single thought. People who do that won't understand the Architecture or WHY stuff works as it does.
>
> Anyone can create a website now and anyone can create an app. But.. Those people can't understand what's been done or how things work. They can ask AI stuff like "What is an SSH and how does CI/CD work?" but understanding how it works in depth and creating stuff with your own hands is what seperates Vibe Coders and Software Developers.
>
> I personally think we are at a time right now where AI Companies fight for market share by allowing free subscriptions.. At some point in the future (if not soon) it'll all move to token based requests. It'll remove a lot of Vibe Coders from the market as it now costs them money to create things instead of just spitting out apps left and right.
>
> AI should be used for guideance - not for solutions. Instead of using Google for a simple answer AI is superior. Anyone who has visited a website these last few years know how annoying it can be. Cookies, ads, pop-ups, newsletter and so on. For a simple answer. That's where I see AI as an advantage. It's also pretty solid for spotting bugs that would be hard to spot with the human eye within a short period of time. But solutions and code should be limited as for my personal opinion.
>
> A great example could be... AI solves a math problem for you. Are you now a Math Genuious or a Math Professor? No. You're just a human who prompted an AI with a problem. It doesn't make you good at math. At all. It's the exact same with Software Development. Anyone can prompt for long enough to get an answer. Knowing what you're doing and what's going on is what seperates the Vibe Coders from the real Developers.
>
> Expectations for 2030 would be: AI is now token based and mainly companies use and buy-in for their employees to use. Vibe Coders have been eliminated expect a few who pay for tokens. A lot of AI slop has been spat out from 2022 - 2030 so people with knowledge need to fix those issues. Which is going to be annoying, but it needs to be done.

### Technology notes

Instead of using a **Hugo Blowfish Template** as my teacher suggests I would like to create something unique and something I can be proud of - instead of using another persons template..

So I'll be creating my AIDA Portfolio using **React, Typescript & Vite**.

I was about to use **Angular** for learning purposes but I figured I'd need to limit learning for now in order to not burn out throughout the course.

I'll be trying to use a **feature/shared** architecture using React as base. React can be spaghetti quickly so I'll be focusing on folders, structure and a red-line throughout the entire code base. Dependencies should be checked and focused on maintained dependencies for safety reasons and for maintainability reasons. That's wheere **Angular** would be superior - but overkill - for this project. It's maintained by Google which means there's basically 0% chance of it ever being deprecated.

While I understand my teachers point of view with **Hugo** and **Blowfish templates** I don't see any reason to use it as the prior semesters been about creating and maintaining our own Backend + Frontend. Why not use the skills we've already been taught? That's my reason for choosing not to use **Hugo**.
